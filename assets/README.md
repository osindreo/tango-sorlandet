# TangoSørlandet – media

Denne mappen er bevisst skilt fra nettsidefilene.

## Bilder
Legg alle bilder i:
`assets/images/`

## Video
Legg lokale videofiler i:
`assets/video/`

Du trenger normalt ikke laste opp eller endre disse filene når du bare gjør endringer i nettsiden.

### Viktig
Filnavn må være de samme som nettsiden forventer. Hvis du ønsker å bytte et bilde uten å endre nettsiden, kan du erstatte filen med en ny fil med samme navn.

Facebook/YouTube-videoer som er innebygd i nettsiden ligger ikke her; de hentes eksternt.
